# Tooded_EFCore — учебный проект для Visual Studio

Простая программа на **C# Windows Forms (.NET 8)** по заданию преподавателя.
Выполнены все четыре части: EF Core + SQL Server LocalDB, CRUD, магазин с вкладками, корзина + PDF + Gmail SMTP.

## Как запустить

1. Распакуйте архив, откройте файл **Tooded_EFCore.sln** в **Visual Studio 2022** (с компонентом «Разработка классических приложений .NET» / `.NET desktop development`).
2. Убедитесь, что установлен **.NET 8 SDK**, и **SQL Server Express LocalDB** (обычно устанавливается с компонентами Visual Studio). Приложение предназначено для Windows.
3. Подождите, пока Visual Studio восстановит NuGet-пакеты (Restore NuGet Packages). Они **уже записаны в проекте** и вручную повторно устанавливать их не нужно.
4. Нажмите **F5** (Start). При первом запуске код автоматически применит EF Core Migration, создаст базу **Tooded_DB**, таблицы **Kategooriatabel**, **Toodetabel** и четыре начальные категории.
5. Откроется главное меню: **Halda tooteid** (товары), **Ava pood** (магазин), **Ostukorv ja arve** (корзина/счёт).

## Проверка по шагам

1. Откройте **Halda tooteid**. Введите название, количество, цену (например, `12,50` или `12.50`), выберите категорию. По желанию нажмите **Vali pilt...** и укажите JPG/PNG. Нажмите **Lisa**.
2. Выберите товар в таблице, измените поля и нажмите **Uuenda**. Для удаления используется **Kustuta**. Через **Lisa valitud toode arvele** выбранный товар можно сразу передать в корзину.
3. Вернитесь в главное меню и откройте **Ava pood**. В каждой вкладке категории отображаются её товары и картинки; по клику на картинку показывается информация.
4. Откройте **Ostukorv ja arve**. Выберите товар, количество и нажмите **Lisa korvi**. Добавьте несколько позиций, нажмите **Genereeri PDF**. Счёт сохранится в папке `Arved` рядом с запущенным EXE.
5. Чтобы отправить PDF, введите **свой Gmail**, **пароль приложения Google** и **почту получателя**. Нажмите **Saada e-mailiga**. Пароль нигде не записывается в файлы или базу.

## Если преподаватель просит показать Migrations

Миграция **InitialCreate уже находится в папке `Migrations`**. Она применяется при запуске через `db.Database.Migrate()`.

В Visual Studio: **Tools → NuGet Package Manager → Package Manager Console**, команда:

```powershell
Update-Database
```

Если нужно именно **своими руками выполнить `Add-Migration InitialCreate`**, сначала удалите в проекте папку `Migrations`, затем в Package Manager Console выполните:

```powershell
Add-Migration InitialCreate
Update-Database
```

Это демонстрирует тот же механизм, но второй раз поверх уже включённой миграции запускать `Add-Migration InitialCreate` не требуется.

В **View → SQL Server Object Explorer** можно увидеть `(localdb)\MSSQLLocalDB → Databases → Tooded_DB`.

## Что делают файлы

- `Toode.cs`, `Kategooria.cs` — модели таблиц.
- `ToodedContext.cs` — EF Core, подключение к LocalDB, связь моделей.
- `Migrations/` — автоматически применяемая миграция схемы.
- `Program.cs` — первое создание базы и стартовые категории.
- `Form1.cs` — главное меню.
- `Form2.cs` — добавление, изменение и удаление товаров.
- `Form3.cs` — просмотр товаров по вкладкам категорий.
- `ArveForm.cs` — корзина, создание PDF, отправка через SMTP.
- `PildiAbi.cs` — копирование и чтение картинок из папки `Images`.
- `*.Designer.cs` — простое расположение элементов Windows Forms.

## Если что-то не работает

- **LocalDB error**: установите SQL Server Express LocalDB или проверьте `(localdb)\MSSQLLocalDB`.
- **Ошибка пакетов**: используйте Restore NuGet Packages и проверьте подключение к NuGet.
- **Нет картинки**: она не обязательна. Папка `Images` создаётся автоматически рядом с EXE. Если картинку удалили, приложение продолжит работать.
- **Не отправляется Gmail**: нужен именно **пароль приложения Google** для учётной записи с двухэтапной проверкой. Обычный пароль Gmail не подойдёт; некоторые аккаунты вообще не предоставляют пароли приложений. Наличие Gmail SMTP и сетевого доступа обязательно.
- **PDF не отправляется**: сначала нажмите **Genereeri PDF**, а уже после этого отправляйте.

> Проект создан как исходный код для Visual Studio. Запуск на настоящем Windows-компьютере с SQL Server LocalDB в этой среде не выполнялся.
